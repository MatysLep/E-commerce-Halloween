# La documentation du projet

Ce dossier rassemble les explications pour comprendre, présenter et exploiter la boutique.

- `AWS Project FISA 2026.pdf` : le sujet d’origine et les attentes pédagogiques.
- `user-experience.png` : la référence initiale du parcours utilisateur.
- `demonstration-locale.png` : capture d’une commande réellement testée dans le navigateur local, avec les trois étapes terminées.
- [`architecture`](architecture/readme.md) : les schémas de la solution hybride et de la cible d’industrialisation.
- [`developpement.md`](developpement.md) : travailler sur le code et comprendre les choix.
- [`deploiement.md`](deploiement.md) : construire et déployer sur AWS.
- [`exploitation.md`](exploitation.md) : diagnostiquer, rejouer et restaurer.
- [`verifications.md`](verifications.md) : les contrôles réellement exécutés et leurs limites.

Pour débuter, lancez d’abord la version locale avec le [README principal](../readme.md), puis lisez le schéma hybride.
